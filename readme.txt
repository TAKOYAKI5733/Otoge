ここでは自作の音ゲー「Simple.notes(仮)」の操作方法(主に譜面製作)の説明をさせていただきます。

【譜面エディターへの入り方】
ジャンル選択->曲選択のところまできて任意の楽曲の場所で[F1]キーを押すことによってこの曲の譜面を編集することができます。

【主な操作方法】
左クリック：ノーツの設置・編集
右クリック：編集ウィンドウの表示・ノーツ削除
ホイール：譜面の時刻の変更
Ctrl+ホイール：ズームイン・ズームアウト
Shift+左ドラッグ：範囲選択

【ショートカットキーについて】
Ctrl+S：保存
Ctrl+C：範囲選択ノーツのコピー
Ctrl+V：コピーしたノーツの貼り付け
Ctrl+R：範囲選択したノーツの左右逆転
Ctrl+M：メトロノーム音の付加

各番号キー：各種ノーツへの変更
１：TAPノーツ
２：LONGノーツ
３：DRAGノーツ
４：DRAG LONGノーツ
５：LANEノーツ

【SPEEDについて】
ノーツの全体速度を変更することができます。ノーツ速度は一瞬で変更することもできれば、徐々に変更したりすることもできます。

【イージングについて】
Straight：直線的にノーツ速度を変更することができます
easeOutCubic：初速が速く、後から遅くなるように速度を変更することができます
easeInCubic：初速が遅く、後から早くなるように速度を変更することができます

【変化にかける時間について】
目標の速度に到達する時間の事です。目標の速度とイージング、変化にかける時間を基準とし関数的に速度を変更できます
　その際にCtrlを押しながらSPEEDの終端をドラッグすることで直感的に変化にかける時間を変更できます

【BPMについて】
設置した部分のBPMと拍子を変更できます

【個別の速度について】
SPEEDを無視して、定義した一定のノーツ速度のノーツを追加します。(太〇の達人でいう追い越しノーツ的なものを作れます)

【曲の追加について】
1.soundsフォルダに.mp3ファイルを入れます
2.scoresフォルダに[新規作成]で新しいフォルダを作成します
3.そのフォルダの中に.jsonファイルを新規作成します。そうすることで音ゲー側が認識してくれます
4.[3]までやった後、音ゲーを開くと自分で作成したフォルダ名が入っているのでその中にある.jsonファイル名のところで[F1]キーを押すことで譜面を制作できます

【難易度について】
譜面エディター画面の左に[Difficulty]という欄があり、そこの[追加]というボタンを押すことによって新規難易度を設定することができます難易度名は[EASY]->[HARD]->[MASTER]の順で色が決まります(すべて大文字)ですが、難易度の名前を自由に決めることができます。

【BPM・Offset・COMPOSER・CREATORなどの各種プロパティの設定について】
画面右上端の歯車のマークを押すことによって各種プロパティの変更をすることができます
